# Design Document

## Why

사진 또는 캔버스 드로잉을 방명록으로 남기고 실시간 벽과 댓글로 공유하는 디지털 방명록 애플리케이션입니다. 프로젝트의 목적과 기술적 판단을 코드와 함께 검증 가능하게 전달합니다.

## What

Realtime Guestbook 프로젝트와 영어·한국어·일본어 문서를 제공합니다.

## Problem

기능 구현만으로는 사용자가 해결하려는 문제, 주요 흐름, 기술 선택, 실행 방법을 저장소 방문자가 빠르게 이해하기 어렵습니다.

## Target Users

- 프로젝트를 평가하는 채용 담당자와 엔지니어
- 소스를 실행하거나 확장하려는 개발자

## Core Features

- 사진 또는 캔버스 드로잉을 방명록으로 남기고 실시간 벽과 댓글로 공유하는 디지털 방명록 애플리케이션
- 기술 스택: React 19, TypeScript, Vite, Supabase Postgres, Storage, Realtime
- 재현 가능한 로컬 실행 및 검증 문서

## Non-goals

- README 작업에서 애플리케이션 동작 변경
- 검증되지 않은 기능 또는 운영 성과 주장

## Product Principles

- 실제 코드와 일치하는 사실만 문서화합니다.
- 민감정보를 문서나 예시에 포함하지 않습니다.
- 세 언어의 핵심 정보 구조를 동일하게 유지합니다.
